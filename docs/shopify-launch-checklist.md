# Shopify Launch Checklist

## Before Products

- Choose final brand name.
- Check domain availability.
- Check trademark risk for the final name.
- Create public support email.
- Confirm legal business name, address, and required public contact info.
- Decide selling countries.
- Decide currency and tax setup.

## Shopify Admin

- Add store policies in Shopify admin.
- Add the policy links to the footer menu.
- Add shipping profiles.
- Connect payment provider.
- Connect Printify.
- Install Shopify Search & Discovery.
- Enable collection filters.
- Test a full checkout in test mode.

## Product Setup

- Create collections from `docs/product-catalog-plan.md`.
- Create products in Printify.
- Sync products to Shopify.
- Standardize product titles, product types, variants, tags, and metafields.
- Add size guides to product descriptions.
- Add care instructions.
- Add production/shipping expectations.

## Theme Setup

- Push this repo to GitHub.
- Connect the GitHub branch to Shopify themes.
- Preview the theme in Shopify.
- Test collection filters.
- Test product variants.
- Test add to cart.
- Test cart update/remove.
- Test checkout.
- Test policy routes.

## Content Needed

- Logo or final wordmark.
- Real product mockups/photos.
- Size charts.
- Product descriptions.
- About text.
- Contact email.
- Shipping windows.
- Return address or return process.
