# Support

## Theme development

Use a GitHub issue for reproducible theme bugs and feature proposals. Search existing issues first and include the affected template, browser/device, Shopify theme context, screenshots with personal data removed, and clear reproduction steps.

General implementation questions can use GitHub Discussions if enabled. The maintainers cannot provide Shopify account access, business registration, tax, legal, payment-provider, or fulfillment-provider advice through repository support.

## Store orders and customer service

GitHub is not a customer-service channel. Do not post order numbers, addresses, receipts, account details, or payment information. Customers should use the contact method displayed on the final storefront. The public support address has not yet been finalized, so no customer-support mailbox is represented by this repository.

## Security

Potential vulnerabilities follow [SECURITY.md](SECURITY.md). Never disclose them in a normal issue or discussion.
